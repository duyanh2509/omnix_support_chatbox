# Omnix Support Chatbox

Hệ thống chatbox hỗ trợ khách hàng thông minh cho Omnix.

## Tính năng

- Chatbot AI hỗ trợ khách hàng 24/7
- Tích hợp với hệ thống CRM
- Giao diện thân thiện, dễ sử dụng
- Hỗ trợ đa ngôn ngữ
